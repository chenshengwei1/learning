糖果消消乐 v3 项目测试计划

1. 文档目的

本文档用于对糖果消消乐 v3（规则驱动架构）进行功能验证、回归检查和交付验收。覆盖核心玩法、双特效交换、多层棋盘（含覆盖物）、事件驱动系统、配置能力、状态系统、模式切换、关卡系统与浏览器表现。

2. 测试目标

  • 棋盘渲染与交互是否正常（点击交换 / 拖拽交换）
  • 直线、田字、斜线匹配规则与最少连消数量是否正确
  • 特效合成规则（4连直线、5连彩虹、田字方块、T/L形炸弹）是否正确
  • 双特效交换组合（line+line、line+bomb、bomb+bomb、rainbow+任意）是否正确
  • 多层棋盘（布局/目标物/障碍物/覆盖物/棋子）数据是否一致
  • 事件驱动系统（onCellCleared、onAdjacent、onAnyMatch 等）是否正确触发
  • 管理员模式多选编辑、游戏模式切换、通关目标结算是否正确
  • 棋盘重排（reshuffle）在无解时能否正常工作
  • 存档系统（localStorage）读写是否正确
  • DOM 一致性检测通过

3. 测试范围

功能验证

  • 基础消除 / 连锁响应 / 计分逻辑 / 步数控制 / 时间限制 / 胜负判断
  • 特效合成（4连直线、5连彩虹、田字方块、T/L形炸弹）
  • 双特效交换组合（4种组合 + fallback）
  • 覆盖物阻挡移动机制（vine）
  • 冰的同格伤害（onCellCleared）vs 藤蔓的相邻伤害（onAdjacent）

配置验证

  • 预设模板切换 / 自定义棋子 / 初始棋盘 / 爆炸规则配置
  • 配置保存与恢复 / 默认配置回退 / 配置解析稳定性
  • 关卡保存与加载（本地关卡库）

特殊状态与障碍验证

  • locked / frozen 状态
  • ice（障碍物）- 同格消除触发
  • vine（覆盖物）- 阻挡移动 + 相邻消除触发
  • chain（障碍物）- 相邻任意消除触发

编辑器验证

  • 单选/多选格子编辑
  • 应用配置与棋盘重建

4. 测试环境

运行环境

  • 浏览器：Chrome、Edge、Firefox 的现代版本
  • 运行方式：直接打开 v3/index.html（或通过 docs/index.html 入口）
  • 依赖项：无额外安装依赖

验收方式

  • 手动交互验证（管理员模式构造场景 + 游戏模式验证）
  • 浏览器控制台检查报错
  • localStorage 检查配置持久化与关卡库（candy_config_v7 / candy_levels_v7）
  • UI 一键测试运行器（__uiTest.run()）

5. 测试用例

5.1 基础匹配测试

TC-01：页面正常加载

目标：页面稳定初始化并展示完整 UI。

步骤：打开 v3/index.html，观察左侧规则面板、中央棋盘、底部操作按钮。

预期：棋盘稳定显示（默认 8×8），分数/步数/连击/时间可见，控制台无脚本错误；加载后棋盘内不存在初始三连。

TC-02：有效交换与消除

目标：相邻棋子合法交换后可形成匹配并消除。

预期：形成 3 连及以上后棋子被移除，分数增加，重力补齐生效，UI 同步更新。

TC-03：无效交换

目标：不构成有效消除的交换不产生错误结果。

预期：操作被拒绝、棋子抖动提示、无错误计分、状态保持一致。

TC-04：点击交换与拖拽交换

目标：两种交互方式均可用。

步骤：①先点击棋子 A 再点击相邻棋子 B 完成交换；②直接按住棋子向相邻方向拖拽超过阈值后松手。

预期：两种方式均触发相同交换逻辑；拖拽越界（棋盘边缘）不报错；模式为管理员时点击应选中格子而非交换。

TC-05：连锁消除与连击

目标：多轮连锁消除可连续执行且计分稳定。

预期：comboCount 递增，多次消除连续执行，分数按连击倍数计算，无卡死或状态异常。

5.2 特效合成测试

TC-06：4 连直线特效

目标：直线 4 连生成对应方向的直线特效。

步骤：构造水平 4 连或垂直 4 连，执行交换。

预期：生成 line-horizontal 或 line-vertical 特效棋子。

TC-07：5 连彩虹特效

目标：直线 ≥5 连生成彩虹特效。

步骤：构造水平 5 连，执行交换。

预期：生成 rainbow 特效棋子。

TC-08：田字方块特效

目标：2×2 田字生成方块特效。

步骤：构造田字形状，执行交换。

预期：生成 square-effect 特效棋子。

TC-09：T 形炸弹

目标：T 形匹配生成炸弹。

步骤：构造 T 形，执行交换。

预期：生成 bomb 特效棋子。

TC-10：L 形炸弹

目标：L 形匹配生成炸弹。

步骤：构造 L 形，执行交换。

预期：生成 bomb 特效棋子。

5.3 双特效交换测试

TC-11：直线 + 直线（同向）

目标：两条同向直线交换，清除整行/整列。

预期：分数 ≥ 100，触发整行/整列消除。

TC-12：直线 + 直线（交叉）

目标：水平直线 + 垂直直线交换，触发十字清除。

预期：触发十字清除效果。

TC-13：直线 + 炸弹

目标：直线 + 炸弹交换，触发三行三列清除。

预期：分数 ≥ 100，3×3 范围清除。

TC-14：炸弹 + 炸弹

目标：两个炸弹交换，触发 5×5 全屏清除。

预期：分数 ≥ 200，5×5 范围清除。

TC-15：彩虹 + 任意特效

目标：彩虹与任意特效交换，触发全屏清除。

预期：分数 ≥ 1000，全屏清除。

5.4 障碍物测试

TC-16：冰（同格伤害）

目标：冰监听 onCellCleared，同格棋子被消除时受伤。

步骤：在格子 (0,2) 放置冰（hp=1），在其同格放置棋子，执行交换使同格棋子消除。

预期：冰被消除。

TC-17：冰（不响应相邻消除）

目标：冰不应响应相邻消除事件。

步骤：在 (1,1) 放置冰（hp=2），在 (0,2) 和 (0,3) 执行消除。

预期：(1,1) 的冰 hp 不变。

TC-18：藤蔓（相邻伤害 + 阻挡移动）

目标：藤蔓监听 onAdjacent，相邻棋子被消除时受伤，且阻挡交换。

步骤 1：在 (0,2) 放置藤蔓（hp=2），交换 (0,2) 和 (0,3) 的棋子。

预期 1：交换被拦截，步数未减。

步骤 2：消除 (0,1)-(0,2)-(0,3) 使藤蔓相邻格子被消除。

预期 2：藤蔓 hp 减少。

TC-19：锁链

目标：锁链监听 onAdjacent（source=any），任意棋子消除时受伤。

预期：相邻消除触发锁链受伤。

5.5 目标物测试

TC-20：水果收集

目标：覆盖在水果上的冰被消除后，水果受到伤害。

步骤：放置西瓜（2×2），上面覆盖冰，消除冰。

预期：西瓜 hp 减少，所有冰清除后西瓜消失。

5.6 模式与功能测试

TC-21：时间限制

目标：计时归零后正确结算。

步骤：开启时间限制并设置短倒计时，切换到游戏模式等待耗尽。

预期：时间递减正确，到 0 结束并弹出结算。

TC-22：步数限制与胜负判定

目标：步数用尽后胜负判定与目标检查一致。

预期：每步递减 1；到 0 时若已达成通关目标判胜，否则判负；低步数时出现预警样式。

TC-23：通关目标（最低分 / 收集目标）

目标：两种通关条件可单独或同时生效。

步骤：启用最低分 5000 并设总步数 30；另启用收集目标，分别验证。

预期：达成任一启用目标即触发胜利结算；HUD 目标区显示进度。

TC-24：提示与重排

目标：提示功能与棋盘重排正常。

步骤：点"提示"按钮观察高亮；构造无可行步盘面后走一步。

预期：提示高亮建议交换并在约 1.5s 后消失；若无可行步，游戏自动重排并稳定化，不卡死。

TC-25：回退功能

目标：undo 可回退到上一步状态。

步骤：执行一次有效交换，点"回退"按钮。

预期：棋盘、分数、步数恢复到交换前状态。

TC-26：管理员模式多选编辑

目标：多选模式下可同时编辑多个格子。

步骤：切换到管理员模式，启用多选，框选多个格子，修改棋子类型后应用。

预期：所有选中格子被统一修改，显示警告信息（如状态不一致）。

5.7 DOM 一致性测试

TC-27：初始状态一致性

目标：初始状态下 Board 数据与 DOM 节点一致。

预期：格子总数、棋子 SVG、障碍物、目标物、层级、位置全部正确。

TC-28：交换后一致性

目标：交换后 Board 数据与 DOM 节点一致。

预期：交换完成后，棋盘数据与 DOM 节点完全同步。

7. 缺陷回归清单

  • 双特效交换后连锁匹配未触发
  • 冰的伤害事件从 onAdjacent 改为 onCellCleared 后回归
  • 覆盖物（vine）阻挡交换机制失效
  • 棋盘重排后仍无可行步
  • 回退时随机数状态未恢复导致棋盘不一致
  • DOM 节点与 Board 数据不同步
  • 多选编辑器状态警告不显示

8. 测试结论

当以上测试用例全部通过时，说明 v3 版本具备稳定的规则驱动架构、完整的双特效交换机制、正确的多层棋盘处理、可靠的配置/关卡持久化，以及可持续扩展的设计基础。

交付判定：建议将该版本视为可演示、可评审、可扩展的规则驱动消消乐引擎；后续扩展玩法时应优先补充自动化回归、配置校验与状态一致性测试。
