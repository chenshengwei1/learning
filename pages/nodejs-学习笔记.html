🚀 Node.js 学习笔记

JavaScript 2026-01-15

📌 什么是 Node.js？

Node.js 是一个基于 Chrome V8 引擎 的 JavaScript 运行时环境。它让 JavaScript 可以脱离浏览器，在服务器端运行，从而构建高性能的网络应用。

Node.js 的核心特点：非阻塞 I/O、事件驱动、轻量高效

📦 模块系统（CommonJS）

Node.js 采用 CommonJS 模块规范，每个文件都是一个独立的模块。

导出模块

// math.js
function add(a, b) {
  return a + b;
}

function subtract(a, b) {
  return a - b;
}

// 方式一：导出单个
module.exports = add;

// 方式二：导出多个
module.exports = { add, subtract };

// 方式三：挂载到 exports 对象
exports.add = add;
exports.subtract = subtract;

导入模块

// app.js
const math = require('./math.js');
console.log(math.add(2, 3)); // 5

核心模块（无需安装）

  • fs — 文件系统操作
  • path — 路径处理
  • http / https — HTTP 服务器
  • os — 操作系统信息
  • events — 事件触发器
  • stream — 流式数据处理

⚡ 异步编程

Node.js 的异步编程有三种主要方式：

1️⃣ 回调函数（Callback）

const fs = require('fs');

fs.readFile('file.txt', 'utf-8', (err, data) => {
  if (err) {
    console.error('读取失败:', err);
    return;
  }
  console.log('文件内容:', data);
});

2️⃣ Promise

const fs = require('fs/promises');

fs.readFile('file.txt', 'utf-8')
  .then(data => console.log('文件内容:', data))
  .catch(err => console.error('读取失败:', err));

3️⃣ async/await（推荐）

const fs = require('fs/promises');

async function readFile() {
  try {
    const data = await fs.readFile('file.txt', 'utf-8');
    console.log('文件内容:', data);
  } catch (err) {
    console.error('读取失败:', err);
  }
}

readFile();

🌐 创建 HTTP 服务器

const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello, Node.js!');
});

server.listen(3000, () => {
  console.log('服务器已启动: http://localhost:3000');
});

📁 文件系统操作

读取文件

const fs = require('fs');

// 同步读取（不推荐用于生产）
const data = fs.readFileSync('file.txt', 'utf-8');

// 异步读取（推荐）
fs.readFile('file.txt', 'utf-8', (err, data) => {
  if (err) throw err;
  console.log(data);
});

写入文件

const fs = require('fs');

const content = '这是要写入的内容';
fs.writeFile('output.txt', content, 'utf-8', (err) => {
  if (err) throw err;
  console.log('文件已保存');
});

目录操作

const fs = require('fs');

// 创建目录
fs.mkdir('my-folder', { recursive: true }, (err) => {
  if (err) throw err;
  console.log('目录已创建');
});

// 读取目录
fs.readdir('.', (err, files) => {
  if (err) throw err;
  console.log('当前目录文件:', files);
});

📊 进程与全局对象

对象 说明

📦 npm 包管理

# 初始化项目
npm init -y

# 安装依赖
npm install express

# 安装开发依赖
npm install --save-dev nodemon

# 全局安装
npm install -g pm2

# 卸载包
npm uninstall express

# 查看已安装的包
npm list --depth=0

🔧 常用内置 API

path — 路径处理

const path = require('path');

path.join('/user', 'local', 'bin');   // /user/local/bin
path.resolve('docs', 'readme.md');    // 绝对路径
path.basename('/a/b/c.js');           // c.js
path.extname('/a/b/c.js');            // .js
path.parse('/a/b/c.js');              // { root, dir, base, ext, name }

os — 操作系统信息

const os = require('os');

os.platform();      // 'win32' / 'darwin' / 'linux'
os.homedir();       // 用户主目录
os.cpus();          // CPU 信息
os.totalmem();      // 总内存
os.freemem();       // 空闲内存

events — 事件触发器

const EventEmitter = require('events');

class MyEmitter extends EventEmitter {}

const myEmitter = new MyEmitter();

// 监听事件
myEmitter.on('event', (data) => {
  console.log('事件触发:', data);
});

// 触发事件
myEmitter.emit('event', { message: 'Hello!' });

💡 最佳实践

  1. 使用 async/await — 避免回调地狱，代码更可读
  2. 错误处理 — 始终捕获异步错误，使用 try/catch
  3. 环境变量 — 敏感信息用 process.env 管理
  4. 模块化 — 按功能拆分模块，单一职责
  5. 使用 .env 文件 — 配合 dotenv 包管理配置
  6. 日志记录 — 使用 winston 或 pino 替代 console.log
  7. 进程管理 — 生产环境用 pm2 管理进程
