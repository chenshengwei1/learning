📄 文档版本：v5 规则引擎 🧩 技术栈：HTML / CSS / JS 🖥️ 浏览器直接运行

1项目简介

本项目是基于浏览器运行的糖果消消乐小游戏，内置管理员模式与游戏模式：既可以作为玩家直接游玩，也可以作为关卡设计器自由配置规则并设计棋盘。

功能亮点

  • 两种模式一键切换（管理员 / 游戏）
  • 预设模板：经典、限时挑战、挑战关卡、围墙模式
  • 可配置消除规则：直线 / 田字 / 斜线、连消数量
  • 可配置通关目标：最低分、消除指定棋子、步数、倒计时
  • 特殊元素：炸弹、锁定、冰冻、冰层、四边围墙
  • 关卡保存与加载、浏览器本地持久化

2运行方式

直接运行

  1. 打开项目目录：C:\doc\work\dsagent2
  2. 找到根目录下的 index.html
  3. 使用浏览器直接打开该文件即可开始游戏
💡 如需浏览项目文档，可打开 docs/index.html，它汇总了设计说明、测试计划与本文档的导航。在游戏页面底部点击「📘 文档」按钮也会跳转到该入口。

3界面总览

游戏主界面分为三块区域：

区域位置作用
左侧面板页面左侧模式切换、通关条件设置、已保存关卡列表、应用配置入口
中央棋盘区页面中间顶部为状态栏，中部为棋盘，底部为操作按钮与消息提示

4模式切换

页面左侧顶部提供两个模式按钮：

模式说明
管理员模式（默认）可配置通关条件、保存规则/关卡、点选格子并编辑属性
游戏模式隐藏编辑类面板，进入正式游玩，开始计分、计时与目标结算

切换方法

  • 点击左侧顶部的「管理员模式」/「游戏模式」按钮；
  • 或使用左下角「切换到游戏模式」按钮与「应用管理员配置」按钮。
⚠️ 修改规则后请先点击「保存规则」或「应用管理员配置」，再切换到游戏模式，否则修改可能不会生效。

5游戏操作

5.1 交换棋子

  • 点击交换：先点击一个棋子选中（高亮），再点击其上下左右的相邻棋子完成交换。
  • 拖拽交换：直接按住棋子向相邻方向拖拽超过一定距离后松手即可交换（可在管理设置中关闭）。
  • 再次点击已选中的棋子可取消选择；点击不相邻的棋子会改选后者。
  • 锁定 / 冰冻状态的棋子无法参与交换。

5.2 消除与计分

  • 横 / 纵方向连续 3 颗及以上同种棋子即可消除（连消数量可配置 3-6）；
  • 开启田字规则时，2×2 同色方块也构成消除；开启斜线规则时，对角线连续同色亦消除；
  • 消除后上方棋子下落补齐；若再次形成匹配则自动连锁，连击数递增、分数翻倍。

5.3 游戏按钮

按钮功能
🔄 重新开始按当前规则重置棋盘重新开局
💡 提示高亮显示一步可形成消除的交换位置；若盘面无可行步会自动洗牌
⚙️ 管理设置打开设置面板，配置模板、棋盘、棋子、规则等
📘 文档跳转到项目文档入口

6爆炸效果

单次消除数量达到阈值时触发爆炸，默认映射如下：

一次消除数量触发爆炸效果
4 连cross 十字爆炸以命中区域中心为原点，向上下左右延伸清除
5 连screen 全屏爆炸清除整个棋盘可消除棋子
6 连blast:2 范围爆炸清除以命中中心为圆心半径 2 的区域
💡 爆炸会清除波及范围内可消除的棋子，也会对围墙造成伤害。三种阈值与爆炸类型均可通过「管理设置 → 爆炸规则」自定义。

7顶部状态栏说明

字段说明
🏆 分数当前得分
👣 剩余步数剩余可走步数（≤5 时变红预警）
💥 连击当前连锁次数
🎯 目标通关目标与进度，例如 50000 · A×10[3/10] 表示需达成 50000 分且消除 A 类棋子 3/10；未启用目标时显示 "—"
⏱️ 时间剩余秒数（启用时间限制时显示，否则显示 ∞；≤10 秒预警）

8通关目标设置（左侧面板）

在管理员模式下可配置以下通关条件，保存后进入游戏模式即生效：

  • 启用最低分通关条件 + 通关最低分数：达到分数即过关；
  • 启用"消除指定类型棋子"通关条件 + 指定棋子类型 + 最低消除数量：消除够指定数量即过关；
  • 开启时间限定模式 + 指定时长（秒）；
  • 总步数：限定总步数。

结算规则

在步数用尽或倒计时归零前，达成任一已启用的通关目标即判胜；若步数 / 时间耗尽仍未达成，则判负。未启用任何分数 / 消除目标时，以步数或时间耗尽作为结束条件。

9管理设置面板（⚙️ 管理设置）

点击游戏区下方的「管理设置」按钮弹出设置面板，可配置：

配置项说明
模板经典 / 限时挑战 / 挑战关卡 / 围墙模式，选择后点「套用模板」
棋盘行数 / 列数（2-20）/ 格子尺寸
棋子配置文本格式定义棋子种类（详见下方格式）
消除规则最少连消数量、总步数、田字形、斜线消除、拖拽交换开关
时间限制是否启用及总时长
初始棋盘自定义布局文本，每行用逗号分隔、行间用回车/分号分隔
爆炸规则分别设置消除 4/5/6 个触发的爆炸类型
计分每颗基础分、连击加倍开关

棋子配置格式

名称:颜色|pattern=图案|pieceColor=主体色|wallTop=true|wallTopHp=2

多个棋子用逗号分隔。支持配置底色、图案层、主体颜色、围墙方向与每边耐久度。

⚠️ 修改完成后点击「保存并应用」立即生效并重开棋盘；「恢复默认」重置所有设置；按 Esc 或点击遮罩可关闭面板。

10棋子属性编辑器（右侧面板）

仅管理员模式可用。点击棋盘任意格子后，可在右侧编辑器修改该格子：

  • 棋子类型：切换为某种糖果，或选「无棋子」清空；
  • 背景图案 / 背景颜色 / 图案颜色：调整格子的视觉样式；
  • 是否可移动：取消勾选 = 给棋子加锁定状态（🔒）；
  • 冰层（0-6）：为格子添加冰层视觉与数值；
  • 四边围墙：分别设置左 / 上 / 右 / 下的围墙强度（无 / 低 / 中 / 高，对应 0/1/2/3 HP）。

操作步骤

  1. 切换到管理员模式；
  2. 点击棋盘上想要修改的格子，右侧面板会显示该格当前属性；
  3. 按需调整类型、图案、颜色、冰层、围墙等属性；
  4. 点击「应用到当前格子」生效，或点「清空当前格子」置空该格。
💡 该编辑器可作为关卡设计器使用，逐格构建自定义盘面后再「保存为关卡」。

11关卡系统

保存为关卡

  1. 在左侧面板填写「关卡名称」；
  2. 点击「保存为关卡」按钮；
  3. 当前规则与整盘棋子状态（含空位、状态、围墙、冰层）会存入浏览器本地关卡库（上限 20 个，同名覆盖）。

加载关卡

  1. 在左侧「已保存关卡」列表中浏览已保存关卡；
  2. 点击对应关卡的「加载」按钮；
  3. 该关卡的规则与棋盘布局即被完整恢复。

12特殊元素说明

元素说明
🔒 锁定 locked不能交换、不能被消除，用于制造障碍
❄️ 冰冻 frozen不能交换（可被正常消除路径处理）
💣 炸弹 bomb参与消除时波及自身周围 3×3
🧊 冰层 ice（0-6 级）视觉与数值层，等级越高透明度越低并显示数字
🧱 围墙 wall按方向独立存在（top/right/bottom/left），各有耐久 HP；被相邻消除/爆炸击中会掉耐久，HP 归零后消失。视觉上低=点线、中=虚线、高=实线

13初始棋盘写法

在「管理设置 → 初始棋盘」中可输入自定义布局，示例：

apple,grape|frozen,orange
orange,empty,apple|bomb
grape,orange,apple|locked
写法含义
empty / - / _ / .空格（无棋子）
apple|frozen苹果并带冻结状态
grape|bomb葡萄并带炸弹状态
apple|locked苹果并带锁定状态

14保存与恢复

  • 自动保存：应用 / 保存配置后自动写入浏览器本地存储（candy_crush_config_v5），刷新或重开页面自动恢复。
  • 恢复默认：在管理设置中点击「恢复默认」，或手动清空本地存储后刷新。
  • 关卡库：独立存储于 candy_crush_levels_v5（上限 20 个）。

15常见问题

页面没有正常显示

确认用浏览器直接打开 index.html，样式与脚本同目录存在，并检查控制台是否有脚本报错；如有旧缓存可强制刷新（Ctrl+F5）。

保存后出现异常字符或乱码

通常由配置解析异常或旧的本地缓存残留导致：清空浏览器本地存储（candy_crush_config_v5 / candy_crush_levels_v5），恢复默认配置后重新应用。

没有可执行的消除步骤

点击「提示」查看建议；或点「重新开始」洗牌。游戏在检测到无可行步时也会自动重排，不会卡死。

棋子无法交换

确认该棋子不是锁定 / 冰冻状态；若在管理员模式下点击棋子是选中用于编辑，请先切换到游戏模式再游玩。

为什么目标区显示多个要求

同时启用了最低分与「消除指定类型棋子」两种通关条件，需按设定规则判定，可在左侧面板调整。
