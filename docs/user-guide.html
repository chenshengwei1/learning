🍬 糖果消消乐 v3 使用手册

📄 文档版本：v3 规则引擎 🧩 技术栈：HTML / CSS / JS 🖥️ 浏览器直接运行 🔧 规则驱动架构

1项目简介

本项目是基于浏览器运行的规则驱动消消 le 游戏引擎。核心设计理念：

  • 引擎无业务：核心代码不包含任何具体游戏内容
  • 内容全配置：所有棋子、特效、障碍、关卡都以 JSON 定义
  • 策划可用：新增元素、修改行为不需要改引擎代码
  • 事件驱动：元素通过监听事件来响应游戏事件

功能亮点

  • 两种模式一键切换（管理员 / 游戏）
  • 多种匹配规则：直线、田字、斜线
  • 丰富的特效系统：直线、炸弹、彩虹、方块
  • 双特效交换组合：产生更强力的效果
  • 多层棋盘：布局/目标物/障碍物/覆盖物/棋子
  • 棋盘重排：无解时自动重排
  • 关卡保存与加载

2运行方式

直接运行

  1. 打开项目目录：C:\doc\work\dsagent2\v3
  2. 找到 index.html
  3. 使用浏览器直接打开即可开始游戏
💡 如需浏览项目文档，可打开 docs/index.html。

3界面总览

游戏主界面分为三块区域：

区域位置作用
左侧面板页面左侧模式切换、通关条件设置、关卡列表、元素库
中央棋盘区页面中间顶部为状态栏，中部为棋盘，底部为操作按钮
格子编辑器弹出面板编辑选中格子的属性（仅管理员模式）

4模式切换

页面左侧顶部提供两个模式按钮：

模式说明
管理员模式（默认）可配置通关条件、保存关卡、编辑格子属性
游戏模式隐藏编辑面板，正式游玩
⚠️ 修改规则后请先点击「保存规则」或「应用配置」，再切换到游戏模式。

5游戏操作

5.1 交换棋子

  • 点击交换：先点击一个棋子选中（高亮），再点击其上下左右的相邻棋子完成交换。
  • 拖拽交换：直接按住棋子向相邻方向拖拽后松手即可交换。
  • 锁定 / 冰冻状态的棋子无法参与交换。

5.2 消除与计分

  • 横 / 纵方向连续 3 颗及以上同种棋子即可消除（连消数量可配置）
  • 开启田字规则时，2×2 同色方块也构成消除
  • 开启斜线规则时，对角线连续同色亦消除
  • 消除后上方棋子下落补齐；若再次形成匹配则自动连锁

5.3 游戏按钮

按钮功能
🔄 重新开始按当前规则重置棋盘重新开局
💡 提示高亮显示一步可形成消除的交换位置
🧪 一键测试运行 UI 测试套件
↩️ 回退回退到上一步状态

6特效系统

通过特殊匹配形状生成特效棋子：

匹配形状生成特效效果
直线 4 连line-horizontal / line-vertical消除整行或整列
直线 ≥5 连rainbow消除所有指定颜色的棋子
田字（2×2）square-effect消除 3×3 范围
T 形 / L 形bomb消除 3×3 范围

7双特效交换

两个特效棋子相邻交换时，触发组合效果：

组合效果
直线 + 直线（同向）清除整行或整列
直线 + 直线（交叉）十字清除（行+列）
直线 + 炸弹三行三列范围清除
炸弹 + 炸弹5×5 范围清除
彩虹 + 任意全屏清除

8顶部状态栏说明

字段说明
🏆 分数当前得分
👣 步数剩余可走步数（≤5 时变红预警）
💥 连击当前连锁次数
⏱️ 时间剩余秒数（启用时间限制时显示）
🎯 目标通关目标与进度

9障碍物说明

障碍物覆盖在棋子上，需要先消除才能到达下方的棋子或目标物：

类型触发方式说明
🧊 冰onCellCleared同格棋子被消除时受伤
⛓️ 锁链onAdjacent相邻任意棋子被消除时受伤
💡 冰只在棋子被同格消除时受伤，相邻消除不会伤害冰。

10覆盖物说明

覆盖物会阻挡玩家的交换操作：

类型特性说明
🌿 藤蔓blocksMovement: true阻挡交换 + 相邻消除时受伤
⚠️ 藤蔓覆盖的格子上的棋子无法参与交换，直到藤蔓被消除。

11目标物说明

目标物是需要保护的水果，覆盖范围内所有障碍物清除后才会消失：

类型说明
🍉 西瓜2×2 大水果
🍇 葡萄1×1 小水果
🍋 柠檬1×1 小水果
🍊 橙子1×1 小水果
🍓 草莓1×1 小水果

12通关目标设置（左侧面板）

在管理员模式下可配置以下通关条件：

  • 最低分通关：达到指定分数即过关
  • 时间限制：在指定时间内完成
  • 总步数：限定总步数

13格子编辑器

仅管理员模式可用。点击棋盘格子后，在弹出面板中可编辑：

  • 棋子类型：选择棋子或清空
  • 特效：为棋子添加特效
  • 障碍物：添加/移除障碍物
  • 目标物：添加/移除目标物

单选/多选模式

编辑器顶部可切换单选或多选模式。多选模式下可以同时编辑多个格子：

  • 按住 Ctrl 点击格子可多选
  • 多选时如果状态不一致，会显示警告信息

14关卡系统

保存为关卡

  1. 在左侧面板填写「关卡名称」
  2. 点击「保存为关卡」按钮
  3. 当前配置存入浏览器本地关卡库

加载关卡

  1. 在左侧「关卡列表」中浏览已保存关卡
  2. 点击「加载」按钮恢复该关卡

15保存与恢复

  • 自动保存：应用/保存配置后自动写入浏览器本地存储（candy_config_v7），刷新后自动恢复。
  • 关卡库：独立存储于 candy_levels_v7。
  • 元素库：自定义元素存储于 candy_elements_v7。

16常见问题

页面没有正常显示

确认用浏览器直接打开 v3/index.html，检查控制台是否有脚本报错；如有旧缓存可强制刷新（Ctrl+F5）。

棋子无法交换

确认该棋子不是锁定/冰冻状态；检查是否有藤蔓覆盖（覆盖物会阻挡交换）；确认在ゲーム模式而非管理员模式。

冰没有受伤

冰只在同格棋子被消除时受伤（onCellCleared），相邻消除不会伤害冰。如果需要冰受伤，请确保有棋子在同格被消除。

没有可执行的消除步骤

点击「提示」查看建议；或等待游戏自动重排。游戏在检测到无可行步时会自动重排，不会卡死。

目标区显示多个要求

同时启用了多个通关条件，需按设定规则判定，可在左侧面板调整。
