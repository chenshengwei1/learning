糖果消消乐项目使用手册

1. 文档目的

本文档面向玩家与项目使用者，说明如何快速启动游戏、切换玩法模式、设置通关目标、使用棋盘编辑器，以及如何理解棋子状态与特殊规则。读完本文档即可完整使用 v5 的全部功能。

2. 项目简介

本项目是基于浏览器运行的糖果消消乐小游戏，内置"管理员模式"与"游戏模式"：既可以作为玩家直接游玩，也可以作为关卡设计器自由配置规则并设计棋盘。

  • 两种模式一键切换（管理员 / 游戏）
  • 预设模板：经典、限时挑战、挑战关卡、围墙模式
  • 可配置消除规则：直线 / 田字 / 斜线、连消数量
  • 可配置通关目标：最低分、消除指定棋子、步数、倒计时
  • 特殊元素：炸弹、锁定、冰冻、冰层、四边围墙
  • 关卡保存与加载、浏览器本地持久化

3. 运行方式

直接运行

  1. 打开项目目录：C:\doc\work\dsagent2
  2. 用浏览器直接打开 index.html

文档入口

如需浏览项目文档，可打开 docs/index.html，它汇总了设计说明、测试计划与本文档的导航。

💡 在游戏页面底部点击「📘 文档」按钮，也会跳转到 docs/index.html。

4. 模式切换

页面左侧顶部提供两个模式按钮：

  • 管理员模式（默认）：可配置通关条件、保存规则/关卡、点选格子并编辑属性。
  • 游戏模式：隐藏编辑类面板，进入正式游玩，开始计分、计时与目标结算。

左下角"切换到游戏模式"按钮与"应用管理员配置"按钮也提供同样的入口。修改规则后请先点「保存规则」或「应用管理员配置」再进入游戏模式。

5. 游戏操作

交换棋子

  • 点击交换：先点击一个棋子选中（高亮），再点击其上下左右的相邻棋子完成交换。
  • 拖拽交换：直接按住棋子向相邻方向拖拽超过一定距离后松手即可交换（可在管理设置中关闭）。
  • 再次点击已选中的棋子可取消选择；点击不相邻的棋子会改选后者。
  • 锁定/冰冻状态的棋子无法参与交换。

消除与计分

  • 横/纵方向连续 3 颗及以上同种棋子即可消除（连消数量可配置 3-6）；
  • 开启田字规则时，2×2 同色方块也构成消除；开启斜线规则时，对角线连续同色亦消除；
  • 消除后上方棋子下落补齐；若再次形成匹配则自动连锁，连击数递增、分数翻倍。

爆炸效果

单次消除数量达到阈值时触发爆炸：默认 4 连十字爆炸、5 连全屏爆炸、6 连范围爆炸（半径 2）。爆炸会清除波及范围内可消除的棋子，也会对围墙造成伤害。

游戏按钮

  • 🔄 重新开始：按当前规则重置棋盘重新开局。
  • 💡 提示：高亮显示一步可形成消除的交换位置；若盘面已无可行步会自动重新洗牌。
  • ⚙️ 管理设置：打开设置面板，配置模板、棋盘、棋子、规则等。
  • 📘 文档：跳转到项目文档入口。

6. 顶部状态栏说明

  • 🏆 分数：当前得分
  • 👣 剩余步数：剩余可走步数（≤5 时变红预警）
  • 💥 连击：当前连锁次数
  • 🎯 目标：通关目标与进度，例如 "50000 · A×10[3/10]" 表示需达成 50000 分且消除 A 类棋子 3/10；未启用目标显示 "—"
  • ⏱️ 时间：剩余秒数（启用时间限制时显示，否则显示 ∞；≤10 秒预警）

7. 通关目标设置（左侧面板）

在管理员模式下可配置以下通关条件，保存后进入游戏模式即生效：

  • 启用最低分通关条件 + 通关最低分数：达到分数即过关；
  • 启用"消除指定类型棋子"通关条件 + 指定棋子类型 + 最低消除数量：消除够指定数量即过关；
  • 开启时间限定模式 + 指定时长（秒）；
  • 总步数：限定总步数。

结算规则：在步数用尽或倒计时归零前，达成任一已启用的通关目标即判胜；若步数/时间耗尽仍未达成，则判负。未启用任何分数/消除目标时，以步数或时间耗尽作为结束条件。

8. 关卡系统

保存为关卡

填写"关卡名称"后点击「保存为关卡」，当前规则与整盘棋子状态（含空位、状态、围墙、冰层）都会存入浏览器本地关卡库（上限 20 个，同名覆盖）。

加载关卡

在左侧"已保存关卡"列表中点击对应关卡的「加载」按钮，即可完整恢复该关卡的规则与棋盘布局。

9. 管理设置面板（⚙️ 管理设置）

点击游戏区下方「管理设置」按钮弹出设置面板：

  • 模板：经典 / 限时挑战 / 挑战关卡 / 围墙模式，选择后点"套用模板"。
  • 棋盘：行数 / 列数（2-20）/ 格子尺寸。
  • 棋子配置：文本格式定义棋子种类，格式：名称:颜色|pattern=图案|pieceColor=主体色|wallTop=true|wallTopHp=2，多个棋子用逗号分隔。
  • 消除规则：最少连消数量、总步数、田字形、斜线消除、拖拽交换开关。
  • 时间限制：是否启用及总时长。
  • 初始棋盘：自定义布局文本，每行用逗号分隔、行间用回车/分号分隔。
  • 爆炸规则：分别设置消除 4/5/6 个触发的爆炸类型：cross（十字）、screen（全屏）、blast:N（半径 N）。
  • 计分：每颗基础分、连击加倍开关。

点击「保存并应用」立即生效并重开棋盘；「恢复默认」重置所有设置；按 Esc 或点击遮罩可关闭。

初始棋盘写法示例

apple,grape|frozen,orange
orange,empty,apple|bomb
grape,orange,apple|locked
  • empty（或 -/_/.）表示空格；
  • apple|frozen 表示苹果并带冻结状态；
  • grape|bomb 表示葡萄并带炸弹状态；
  • apple|locked 表示苹果并带锁定状态。

10. 棋子属性编辑器（右侧面板）

仅管理员模式可用。点击棋盘任意格子后，可在右侧编辑器修改该格子：

  • 棋子类型：切换为某种糖果，或选"无棋子"清空；
  • 背景图案 / 背景颜色 / 图案颜色：调整格子的视觉样式；
  • 是否可移动：取消勾选 = 给棋子加锁定状态（🔒）；
  • 冰层（0-6）：为格子添加冰层视觉与数值；
  • 四边围墙：分别设置左/上/右/下的围墙强度（无 / 低 / 中 / 高，对应 0/1/2/3 HP）。

修改后点「应用到当前格子」生效，点「清空当前格子」置空该格。可作为关卡设计器使用。

11. 特殊元素说明

  • 🔒 锁定 locked：不能交换、不能被消除，用于制造障碍。
  • ❄️ 冰冻 frozen：不能交换（可被正常消除路径处理）。
  • 💣 炸弹 bomb：参与消除时波及自身周围 3×3。
  • 🧊 冰层 ice（0-6 级）：视觉与数值层，等级越高透明度越低并显示数字。
  • 围墙 wall：按方向独立存在（top/right/bottom/left），各有耐久 HP；被相邻消除/爆炸击中会掉耐久，HP 归零后消失。视觉上低=点线、中=虚线、高=实线。

12. 保存与恢复

  • 自动保存：应用/保存配置后自动写入浏览器本地存储，刷新或重开页面自动恢复。
  • 恢复默认：在管理设置中点击"恢复默认"，或手动清空本地存储后刷新。

13. 常见问题

页面没有正常显示

确认用浏览器直接打开 index.html、样式与脚本同目录存在，并检查控制台是否有脚本报错；如有旧缓存可强制刷新（Ctrl+F5）。

保存后出现异常字符或乱码

通常由配置解析异常或旧的本地缓存残留导致：清空浏览器本地存储（localStorage 中 candy_crush_config_v5 / candy_crush_levels_v5），恢复默认配置后重新应用。

没有可执行的消除步骤

点击"提示"查看建议；或点"重新开始"洗牌；游戏在检测到无可行步时也会自动重排，不会卡死。

棋子无法交换

确认该棋子不是锁定/冰冻状态；若在管理员模式下点击棋子是选中用于编辑，请先切换到游戏模式再游玩。

为什么目标区显示多个要求

同时启用了最低分与"消除指定类型棋子"两种通关条件，需全部达成（或按设定规则判定）才可过关，可在左侧面板调整。

14. 总结

本游戏既是可玩的消消乐原型，也是可配置、可扩展的关卡设计工具。玩家只需切换到游戏模式即可体验完整玩法；设计者则可在管理员模式中自由配置规则、编辑棋盘并保存为关卡。

适用场景：前端游戏原型演示、规则设计教学、关卡制作、玩法扩展实验和团队评审材料。
