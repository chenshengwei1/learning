#  Leaning 智能助手

> **一个自改进的 AI Agent，基于 LangGraph + DeepSeek，具备完整工具链的智能开发助手**

---

##  项目简介

**Leaning** 是一个**可自我迭代的智能开发助手**。它不是一个传统的"问答机器人"，而是一个**能实际操作文件系统、执行命令、管理 Git、查询信息**的 AI Agent。

更特别的是，它自己**就是自己的维护者**——它可以读取自己的代码、修改自己的代码、重启自己。这是一个真正的**自改进 AI 系统**。

Q - 如何查看Import xxx报错信息？
