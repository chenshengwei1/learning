# 如何添加copilot chat的大模型

## 1、安装copilot chat插件

在vscode中安装copilot chat插件，安装完成后，点击左侧的copilot chat图标，选择登录即可。

## 2、添加大模型

在vscode中打开命令面板（Ctrl+Shift+P），输入“Copilot Chat: Settings”，选择“Copilot Chat: Settings”选项，进入设置页面。

在设置页面中，找到“Copilot Chat: Model”选项，点击“Add Model”按钮，输入大模型的名称和API地址，点击“Save”按钮即可。

## 2.1 或者
在vscode中打开命令面板（Ctrl+Shift+P），输入“Chat: Manange Language Models”，选择“Chat: Manange Language Models”选项，进入设置页面。

# 2.1.1 点击Add Models,选择custom end point



## 3、使用大模型

在使用copilot chat时，可以通过选择不同的大模型来获取不同的代码建议。
